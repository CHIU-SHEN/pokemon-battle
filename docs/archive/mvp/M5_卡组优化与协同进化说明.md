## 2. 合法性检查

检查规则：

- 总数必须 60；
- Card ID 必须存在；
- 非基础能量同名最多 4；
- ACE SPEC 最多 1；
- 至少 1 张 Basic Pokemon；
- 输出错误原因和基础统计。

本地验证：

```text
sample deck: legal
59-card deck: illegal
5-copy Snover: illegal
2 ACE SPEC: illegal
```

## 6. 协同进化纪律

`data/deck_coevolution_plan.json` 记录后续流程：

1. 将 elite deck 复制到临时 submission；
2. 用 M2 league 跑 Random / Sample / Exploiter / V0-best；
3. 分别记录 deck-only、strategy-only、deck+strategy；
4. 只有外部基线提升且 exploiter 不退化时才晋级；
5. 若低能量/高 tech 候选晋级，再调整 V0/V1 权重并新增战术测试。
