# M3 V1 约束粒子信念 + 有界搜索说明

更新时间：2026-07-06

## 1. 已完成内容

M3 已实现为可开关的 V1 搜索层，V0 仍是安全底座：

- `submission/agent/belief.py`：约束粒子采样，生成 Search API 所需隐藏状态；
- `submission/agent/action_gen.py`：联合动作候选生成，包含 V0、top-k、空选、随机扰动；
- `submission/agent/value.py`：启发式叶节点价值；
- `submission/agent/search.py`：Search API 生命周期封装、Gumbel 根搜索、风险敏感选择；
- `baselines/v0_best/main.py`：冻结纯 V0 基线；
- `tests/test_m3_search.py`：粒子、候选、Search API smoke test；
- `jobs/m3_search_eval.slurm`：服务器 CPU 搜索评估模板。

## 2. 开关与预算

当前默认提交保护性关闭搜索，即不设置环境变量时仍走 V0。

开启 V1：

```bash
export PTCG_ENABLE_SEARCH=1
export PTCG_SEARCH_CANDIDATES=4
export PTCG_SEARCH_PARTICLES=2
export PTCG_SEARCH_NODE_BUDGET=64
export PTCG_SEARCH_TIME_BUDGET=0.025
export PTCG_SEARCH_SWITCH_MARGIN=175
```

关闭 V1：

```bash
export PTCG_ENABLE_SEARCH=0
```

说明：搜索只在关键 context 尝试；Search API、采样、预算、候选评估任一失败，都会退回 V0。

## 4. Search API 生命周期

`SearchManager` 对每个根搜索执行：

```text
BeliefSampler.sample
  -> search_begin
  -> search_step(candidate)
  -> evaluate leaf
  -> search_release child/root
  -> search_end
```

异常处理：

- 每个候选分支独立 try/finally；
- 子状态和根状态尽量释放；
- 根搜索结束调用 `search_end()`；
- 任何异常不影响 agent 返回合法 V0 动作。
